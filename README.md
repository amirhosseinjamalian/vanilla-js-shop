# 🚀 AmirShop – Dynamic Product Loader

A clean and simple web shop application that fetches products from a **live API (FakeStore API)** and displays them as product cards using **Vanilla JavaScript**.

---

## ▶️ Live Demo
🔗 **Demo Online:** 
[🔗Click here to view the live demo](https://amirhosseinjamalian.github.io/vanilla-js-shop/)

---

## 📌 Overview

AmirShop demonstrates:  
- Fetching live product data from an API  
- Handling asynchronous requests with Promises  
- Rendering dynamic product cards in DOM  
- Basic E-commerce UI layout  
- Hover effects and responsive design  

---

## ✨ Features

✅ Fetch products from FakeStore API  
✅ Display product image, title, price, category, description  
✅ Add to Cart button (UI only)  
✅ Dynamic DOM creation  
✅ Loading and error handling  
✅ Clean UI + Hover effects

## 🧠 How It Works

1️⃣ On page load, fetch products using `fetch()`  
2️⃣ Convert JSON response  
3️⃣ Dynamically create a card for each product  
4️⃣ Add to DOM inside `.products` container  
5️⃣ Handle fetch errors with a fallback message
